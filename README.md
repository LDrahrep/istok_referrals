# Istok Referrals

Telegram-бот для приёма рекомендаций кандидатов от действующих сотрудников Istok. Сотрудник подтверждает, что работает в компании (emplid из QR на бейдже + сверка с таблицей), и отправляет данные кандидата.

Статус: сбор требований, кода пока нет.

- [docs/01-tz-review.md](docs/01-tz-review.md) — разбор ТЗ: риски, пробелы, открытые вопросы
