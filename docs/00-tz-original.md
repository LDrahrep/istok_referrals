# ТЗ (исходная версия, без правок)

Создаем бота Istok Referrals.

Суть:
мы имеем список работников, и нам нужно его расширить.
Для этого мы заведем telegram бота, который будет принимать рекомендации от уже существующих сотрудников.

Необходимая информация о новых людях:

1. Имя фамилия
2. Номер телефона
3. Почта
4. Работал ли когда-то уже у нас? Да/нет
5. Фото ворка
6. Кто его рекомендует. (Имя фамилия человека кто заполнил данные)

чтоб мы точно могли быть уверены в том, что пользователя приглашает наш работник, нужно добавить проверку.
У каждого работника есть emplid, вшитый в QR код.
Если телеграм бот сможет как-то считать этот код и обратиться к таблице, то это будет лучший вариант.
